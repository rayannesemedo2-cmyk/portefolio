Missão 1: Os Elétricos com Flexbox e Grid
Criem a pasta sessao-10 dentro de exercicios-uf1.1 e copiem para lá todo o conteúdo da pasta sessao-09.
Em eletricos-lisboa.html, envolvam os cinco cartões das linhas numa <div class="grelha-linhas"> e a tabela numa <div class="tabela-responsiva">.
Em css/eletricos.css: o menu de "pílulas" com Flexbox (em vez de inline-block), a grelha das linhas com repeat(auto-fit, minmax(260px, 1fr)) e a tabela a deslizar no telemóvel.
Escrevam o h1 com o tamanho do telemóvel e uma media query que o aumenta a partir de 768px.
Façam o ciclo de trabalho no Git: git add ., git commit -m "Adiciona Flexbox e Grid a pagina dos Eletricos", git push.
Missão 2: A Página dos Mercados Tradicionais
Copiem o texto de mercados-portugal.txt e a imagem mercado.svg para a vossa pasta sessao-10 (a imagem vai para imagens/).
Criem mercados-portugal.html: cabeçalho com a imagem e o título lado a lado (numa div class="cabecalho"), menu, seis cartões numa div class="grelha-mercados", uma tabela de resumo e uma caixa de dicas.
Criem css/mercados.css mobile-first: uma coluna de cartões no telemóvel, duas a partir de 600px e três a partir de 960px; no cabeçalho, a imagem por cima do título no telemóvel e ao lado do título a partir de 600px.
Façam o ciclo de trabalho no Git: git add ., git commit -m "Cria pagina dos Mercados Tradicionais", git push.
Missão 3: Detetives do Layout
Abram mercados-portugal.html no modo de dispositivo das DevTools e anotem quantas colunas de cartões há com 375px, 700px e 1200px.
Encontrem nas DevTools as etiquetas flex e grid e ativem-nas para ver os contentores desenhados na página.
Descubram a largura exata em que o cabeçalho muda de coluna para linha.
Critérios de sucesso:
O menu das duas páginas usa Flexbox, com gap e flex-wrap.
As grelhas de cartões usam Grid, com gap e sem margens a mais entre os cartões.
O CSS de mercados.css é mobile-first, com duas media queries min-width no fim do ficheiro.
Com 375px de largura, nenhuma página tem barra de deslizar horizontal.
O validador do W3C não mostra erros de HTML.
O repositório no GitHub tem os commits das Missões 1 e 2.
